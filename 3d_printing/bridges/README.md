# alternative methods of printing bridges

inspired by [hackaday article](https://hackaday.com/2025/11/05/better-3d-printed-bridges-are-possible-with-the-right-settings/)
featuring [YT video](https://youtu.be/xQBLv3cPUbo).

TL;DR the idea is print slowly and extrude a lot:
* `bridge_flow_ratio = 1.5` (x)
* `bridge_speed = 10` (mm/s)
needs superb cooling.

on my Voron 2.4 it's more like 1.0 flow and 5mm/s speed to look nice.
however much better (and faster!) it is to just print with the support (7m17s vs. 5m12s with supports).
